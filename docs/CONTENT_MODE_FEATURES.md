# Nexa Content Mode - Complete Feature List

## 📚 Study Tools (4 features)

### 1. Extract Key Terms
**Command**: "Extract key terms" / "What are the key terms?"
**Mode**: `extract_terms`
**Output**: List of 10-15 important terms with definitions
**Use case**: Quickly identify vocabulary to study

### 2. Generate Flashcards
**Command**: "Make flashcards" / "Create study cards"
**Mode**: `flashcards`
**Output**: 8-12 question/answer pairs for memorization
**Use case**: Active recall study method

### 3. Study Questions
**Command**: "Create study questions" / "Give me test questions"
**Mode**: `study_questions`
**Output**: 6-10 questions at various difficulty levels
**Use case**: Self-testing and exam preparation

### 4. Difficulty Check
**Command**: "Check difficulty level" / "What reading level is this?"
**Mode**: `difficulty_check`
**Output**: Grade level, complexity analysis, appropriate audience
**Use case**: Assess if content is appropriate for target audience

## ✍️ Writing Enhancement (8 features)

### Original 6 Modes:
1. **Formal** - Professional tone for business/academic
2. **Shorter** - Concise version (30-40% reduction)
3. **Grammar Only** - Fix errors without changing style
4. **Improve** - Enhance clarity and flow
5. **Summarize** - Key points and main ideas
6. **Casual** - Friendly conversational tone

### New 4 Modes:

### 7. Paraphrase
**Command**: "Paraphrase this" / "Rewrite in different words"
**Mode**: `paraphrase`
**Output**: Completely reworded version with same meaning
**Use case**: Avoid plagiarism, understand concepts better

### 8. Expand
**Command**: "Expand this" / "Add more detail"
**Mode**: `expand`
**Output**: 50-100% longer with supporting details
**Use case**: Develop brief notes into full paragraphs

### 9. Simplify
**Command**: "Simplify this" / "Make it easier to understand"
**Mode**: `simplify`
**Output**: 6th-8th grade reading level version
**Use case**: Explain complex topics to younger students

### 10. Academic Tone
**Command**: "Make it academic" / "Convert to scholarly style"
**Mode**: `academic`
**Output**: Formal scholarly writing suitable for research papers
**Use case**: Transform notes into academic papers

## 📊 Content Organization (2 features)

### 1. Create Outline
**Command**: "Create an outline" / "Outline this content"
**Mode**: `outline`
**Output**: Hierarchical structure (I, A, 1, a format)
**Use case**: Organize thoughts, structure essays

### 2. Add Section Headings
**Command**: "Add headings" / "Organize with headings"
**Mode**: `add_headings`
**Output**: Original text with section headings inserted
**Use case**: Improve readability of long documents

## 📄 PDF Export (3 formats)

1. **Simple Text** - Plain paragraphs
   - Command: "Create PDF as [name]"
   
2. **With Bullets** - Bullet points with section headings
   - Command: "Create PDF with bullets as [name]"
   
3. **Formatted** - Advanced formatting with justified text
   - Command: "Create formatted PDF as [name]"

## 🎯 Usage Examples

### Study Session Workflow:
1. Paste lecture notes → "Extract key terms"
2. Review terms → "Make flashcards" 
3. Study flashcards → "Create study questions"
4. Test yourself → "Create PDF with bullets as Study_Guide"

### Essay Writing Workflow:
1. Paste rough draft → "Check difficulty level"
2. If too simple → "Make it academic"
3. If too complex → "Simplify this"
4. Add structure → "Add headings"
5. Final polish → "Fix grammar"
6. Export → "Create formatted PDF as Essay_Final"

### Research Paper Workflow:
1. Paste notes → "Create an outline"
2. Expand sections → "Expand this" (section by section)
3. Academic style → "Make it academic"
4. Review → "Check difficulty level"
5. Polish → "Improve"

---

## 💡 Pro Tips

- **Content Mode stays active** - No need to reopen for each operation
- **Chain operations** - Process text multiple times with different modes
- **Paste once, process many times** - Try different modes on same content
- **PDF naming** - Be specific: "Chapter_3_Summary" not just "summary"
- **Flashcards** - Works best with 200-500 words of content
- **Outlines** - Best for structured content (essays, articles, chapters)
