# Model Directory
Place your Whisper.cpp model files here:

## Recommended Models:
- **ggml-base.en.bin** (140 MB) - Best balance of speed and accuracy
- **ggml-small.en.bin** (480 MB) - Higher accuracy, slower
- **ggml-tiny.en.bin** (75 MB) - Fastest, lower accuracy

## Download From:
https://huggingface.co/ggerganov/whisper.cpp

## Binary:
Also place the `whisper.exe` (or `whisper` on Linux) binary in this directory.

Download from: https://github.com/ggerganov/whisper.cpp/releases
